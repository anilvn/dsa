## 31. Reverse Words in a Sentence

```java
import java.util.stream.Stream;

public class ReverseWord {

    public static void main(String[] args) {

        String str = "I love java";

        // Reverse words
        String result =
                Stream.of(str.split(" "))
                        .reduce(
                                "",
                                (prev, next) -> next + " " + prev
                        );

        System.out.println(result.trim());
    }
}
```

## 35. Find Common Elements Between Two Lists

```java
import java.util.Arrays;
import java.util.List;

public class FindCommonElements {

    public static void main(String[] args) {

        List<Integer> list1 =
                Arrays.asList(1, 2, 3, 4, 5);

        List<Integer> list2 =
                Arrays.asList(3, 4, 5, 6, 7);

        // Keep only common elements
        List<Integer> result =
                list1.stream()
                        .filter(list2::contains)
                        .toList();

        System.out.println(result);
    }
}
```

## 36. Reverse Only Vowels in a String

```java
public class ReverseVowels {

    public static void main(String[] args) {

        String s = "icecream";

        char[] c = s.toCharArray();

        int left = 0;
        int right = c.length - 1;

        while (left < right) {

            while (left < right &&
                    !isVowel(c[left])) {
                left++;
            }

            while (left < right &&
                    !isVowel(c[right])) {
                right--;
            }

            // Swap vowels
            char temp = c[left];
            c[left] = c[right];
            c[right] = temp;

            left++;
            right--;
        }

        System.out.println(new String(c));
    }

    static boolean isVowel(char ch) {

        return "aeiouAEIOU"
                .indexOf(ch) != -1;
    }
}
```

## 37. Move All 1's To End of Array

```java
import java.util.Arrays;

public class MoveOnesToEnd {

    public static void main(String[] args) {

        int[] arr = {0, 1, 2, 1, 3, 1, 8};

        int p = 0;

        // Place non-1 elements first
        for (int i = 0; i < arr.length; i++) {

            if (arr[i] != 1) {
                arr[p] = arr[i];
                p++;
            }
        }

        // Fill remaining positions with 1
        while (p < arr.length) {
            arr[p] = 1;
            p++;
        }

        System.out.println(
                Arrays.toString(arr)
        );
    }
}
```

## 38. Find Longest Word in a Sentence

```java
import java.util.Arrays;
import java.util.Comparator;

public class LongestWord {

    public static void main(String[] args) {

        String s = "good morning everyone";

        // Find longest word
        String result =
                Arrays.stream(s.split(" "))
                        .max(
                                Comparator.comparingInt(
                                        String::length
                                )
                        )
                        .orElse("");

        System.out.println(result);
    }
}
```

## 39. Why array.length Has No Brackets but list.size() Has Brackets?

```java
// Array

int[] arr = {1, 2, 3};

System.out.println(arr.length);

// length is a public final field
// Field access does not require ()
```

```java
// List

List<Integer> list =
        Arrays.asList(1, 2, 3);

System.out.println(list.size());

// size() is a method
// Method invocation requires ()
```

```text
Interview Answer:

Array:
- length is a built-in field/property.
- JVM stores it as part of array object.
- Accessed as arr.length.

List:
- size() is a method declared in Collection interface.
- Different implementations can calculate or maintain size differently.
- Invoked as list.size().

Therefore:
arr.length      -> field
list.size()     -> method
```

## 40. Reverse Each Word But Keep Word Order

```java
import java.util.Arrays;
import java.util.stream.Collectors;

public class ReverseEachWord {

    public static void main(String[] args) {

        String str = "I love java";

        // Reverse each word individually
        String result =
                Arrays.stream(str.split(" "))
                        .map(word ->
                                new StringBuilder(word)
                                        .reverse()
                                        .toString()
                        )
                        .collect(
                                Collectors.joining(" ")
                        );

        System.out.println(result);
    }
}
```
