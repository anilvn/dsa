## Zero → Hero Binary Search Mastery Roadmap


## Level 1: Binary Search Fundamentals

### Core Problems

* Binary Search (Iterative)
* Binary Search (Recursive)
* Overflow Cases in Binary Search
* Search Element in Sorted Array

### Key Concepts

* Low, High, Mid logic
* Iteration vs recursion
* O(log n) intuition

---

## Level 2: Boundaries (Very Important)

### Core Problems

* Lower Bound (first element ≥ x)
* Upper Bound (first element > x)
* Search Insert Position
* Floor of a Number (largest element ≤ x)
* Ceil of a Number (smallest element ≥ x)

### Key Concepts

* Boundary-based binary search
* Lower bound = Ceil logic
* Upper bound helps in frequency counting

---

## Level 3: First / Last Occurrence Patterns

### Core Problems

* First Occurrence in Array
* Last Occurrence in Array
* Count Occurrences of Element

### Key Concepts

* Modified binary search conditions
* Shrinking search space strategically

---

## Level 4: Rotated Sorted Array Problems

### Core Problems

* Search in Rotated Sorted Array (No duplicates)
* Search in Rotated Sorted Array (With duplicates)
* Find Minimum in Rotated Sorted Array
* Find Maximum in Rotated Sorted Array
* Number of Rotations in Array

### Key Concepts

* One half is always sorted
* Identify sorted half and eliminate other half
* asc/dec

---

## Level 5: Special Binary Search Problems

### Core Problems

* Single Element in Sorted Array
* Find Peak Element
* K-th Missing Positive Number

### Key Concepts

* Binary search on structure, not just index

---

## Level 6: Binary Search on Answer (Very Important Pattern)

### Core Problems

* Sqrt of a Number
* Nth Root of a Number
* Koko Eating Bananas
* Minimum Days to Make M Bouquets
* Smallest Divisor Given Threshold
* Capacity to Ship Packages within D Days

### Key Concepts

* Optimize min/max value using binary search
* Feasibility check function is critical

---

## Level 7: Allocation and Partition Problems (Hard)

### Core Problems

* Aggressive Cows
* Allocate Books
* Painter’s Partition
* Split Array Largest Sum

### Key Concepts

* Check if a mid value is feasible
* Binary search on answer space

---

## Level 8: Advanced Optimization Problems

### Core Problems

* Minimize Maximum Distance between Gas Stations

### Key Concepts

* Precision-based binary search or heap approach

---

## Level 9: Matrix / 2D Binary Search

### Core Problems

* Row with Maximum 1s
* Search in 2D Matrix I
* Search in 2D Matrix II
* Peak Element in 2D Matrix
* Median in Row Wise Sorted Matrix

### Key Concepts

* Treat matrix as flattened array or row-wise search
* Efficient elimination of search space

---

## Level 10: Median and Advanced Two Array Problems

### Core Problems

* Median of Two Sorted Arrays (Brute Force)
* Median of Two Sorted Arrays (Optimal Binary Search)
* K-th Element of Two Sorted Arrays

### Key Concepts

* Partition-based binary search
* Handling two sorted arrays simultaneously

---

## Core Binary Search Patterns Summary

### Pattern 1: Standard Search

* Element search
* First/Last occurrence

### Pattern 2: Boundary Search

* Lower bound
* Upper bound
* Floor / Ceil

### Pattern 3: Rotated Arrays

* Identify sorted half
* Eliminate one half

### Pattern 4: Binary Search on Answer

* Minimize / maximize problems
* Feasibility function required

### Pattern 5: Matrix Binary Search

* 2D search optimization
* Row-wise or virtual flattening

---

## Final Insight

Mastering these patterns is enough to solve most binary search interview problems:

* Basic binary search
* Boundary problems
* Rotated arrays
* Binary search on answer
* Matrix-based search
