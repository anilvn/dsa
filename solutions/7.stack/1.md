# Next Greater Element (NGE)

### Problem Statement

* For every element in the array, find the first greater element on its right side.
* If no greater element exists, return `-1`.

---

### Example

#### Input

```text
arr = [4, 5, 2, 10, 8]
```

#### Output

```text
[5, 10, 10, -1, -1]
```

---

### Idea / Intuition

* Use a monotonic decreasing stack
* Traverse from right to left
* Remove smaller or equal elements from stack
* Top of stack becomes next greater element

---

### Optimized Approach

### steps for optimized approach

1. Traverse array from right to left
2. Remove all smaller elements from stack
3. If stack is empty → answer is `-1`
4. Else top of stack is answer
5. Push current element into stack

### Java Code

```java
import java.util.*;

public class NextGreaterElement {

    public static int[] nextGreater(int[] arr) {

        int n = arr.length;
        int[] res = new int[n];

        Stack<Integer> stack = new Stack<>();

        for (int i = n - 1; i >= 0; i--) {

            while (!stack.isEmpty() && stack.peek() <= arr[i]) {
                stack.pop();
            }

            res[i] = stack.isEmpty() ? -1 : stack.peek();

            stack.push(arr[i]);
        }

        return res;
    }

    public static void main(String[] args) {

        int[] arr = {4, 5, 2, 10, 8};

        System.out.println(Arrays.toString(nextGreater(arr)));
    }
}

// Time Complexity - O(N)
// Space Complexity - O(N)
```

# Next Greater Element II (Circular Array)

### Problem Statement

* Find the next greater element for every element in a circular array.
* Array wraps around after the last index.

---

### Example

#### Input

```text
arr = [1, 2, 1]
```

#### Output

```text
[2, -1, 2]
```

---

### Idea / Intuition

* Traverse array twice from right to left
* Use stack to maintain greater elements
* `% n` handles circular movement

---

### Optimized Approach

### steps for optimized approach

1. Traverse from `2*n - 1` to `0`
2. Use `i % n` to access circular index
3. Remove smaller elements from stack
4. Store result only during first traversal

### Java Code
```java
    public static int[] nextGreaterElement2(int[] arr) {

        int n = arr.length;
        int[] result = new int[n];
        Arrays.fill(result, -1);

        for (int i = 0; i < n; i++) {

            for (int j = 1; j < n; j++) {
                // nextIndex = (2 + 1) % 3 = 3 % 3 = 0
                int nextIndex = (i + j) % n;

                if (arr[nextIndex] > arr[i]) {
                    result[i] = arr[nextIndex];
                    break;
                }
            }
        }

        return result;
    }
```

```java
import java.util.*;

public class NextGreaterElementII {

    public static int[] nextGreaterElements(int[] arr) {

        int n = arr.length;
        int[] res = new int[n];

        Stack<Integer> stack = new Stack<>();

        for (int i = 2 * n - 1; i >= 0; i--) {

            int current = arr[i % n];

            while (!stack.isEmpty() && stack.peek() <= current) {
                stack.pop();
            }

            if (i < n) {
                res[i] = stack.isEmpty() ? -1 : stack.peek();
            }

            stack.push(current);
        }

        return res;
    }

    public static void main(String[] args) {

        int[] arr = {1, 2, 1};

        System.out.println(Arrays.toString(nextGreaterElements(arr)));
    }
}

// Time Complexity - O(N)
// Space Complexity - O(N)
```

2. Remove larger elements from stack

# Previous Greater Element (PGE)

### Problem Statement

* Find the first greater element on the left side for every element.
* If not found, return `-1`.

---

### Example

#### Input

```text
arr = [15, 10, 18, 12, 4, 6, 2, 8]
```

#### Output

```text
[-1, 15, -1, 18, 12, 12, 6, 12]
```

---

### Idea / Intuition

* Traverse from left to right
* Maintain decreasing stack
* Stack top gives previous greater element

---

### Optimized Approach

### steps for optimized approach

1. Traverse array from left to right
2. Remove smaller elements from stack
3. Stack top becomes previous greater
4. Push current element

### Java Code

```java
import java.util.*;

public class PreviousGreaterElement {

            while (!stack.isEmpty() && stack.peek() <= arr[i]) {
                stack.pop();
            }

            res[i] = stack.isEmpty() ? -1 : stack.peek();

            stack.push(arr[i]);
        }

        return res;
    }

    public static void main(String[] args) {

        int[] arr = {15, 10, 18, 12, 4, 6, 2, 8};

        System.out.println(Arrays.toString(previousGreater(arr)));
    }
}

// Time Complexity - O(N)
// Space Complexity - O(N)
```

# Stock Span Problem

### Problem Statement

* For every day, find how many consecutive previous days had price less than or equal to current price.

---

### Example

#### Input

```text
prices = [100, 80, 60, 70, 60, 75, 85]
```

#### Output

```text
[1, 1, 1, 2, 1, 4, 6]
```

---

### Idea / Intuition

* Use stack to store indices
* Remove smaller prices
* Difference between indices gives span

---

### Optimized Approach

### steps for optimized approach

1. Traverse prices array
2. Remove all smaller or equal prices
3. If stack empty → span = `i + 1`
4. Else span = `i - stack.peek()`
5. Push current index
```
Span = currentIndex - previousGreaterIndex
```
### Java Code

```java
import java.util.*;

public class StockSpanProblem {

    public static int[] stockSpan(int[] prices) {

        int n = prices.length;
        int[] span = new int[n];

        Stack<Integer> stack = new Stack<>();

        for (int i = 0; i < n; i++) {

            // Span = currentIndex - previousGreaterIndex
            while (!stack.isEmpty() && prices[stack.peek()] <= prices[i]) {
                stack.pop();
            }

            span[i] = stack.isEmpty() ? i + 1 : i - stack.peek();

            stack.push(i);
        }

        return span;
    }

    public static void main(String[] args) {

        int[] prices = {100, 80, 60, 70, 60, 75, 85};

        System.out.println(Arrays.toString(stockSpan(prices)));
    }
}

// Time Complexity - O(N)
// Space Complexity - O(N)
```
