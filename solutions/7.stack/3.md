# Trapping Rain Water (Stack Approach)

### Problem Statement

* Given an array where each element represents building height, find how much rain water can be trapped.

---

### Example

#### Input

```text id="m2b1oq"
height = [4,2,0,3,2,5]
```

#### Output

```text id="5n2a5d"
9
```

---

### Idea / Intuition

* Water gets trapped between taller buildings
* Stack helps find left and right boundaries
* When current bar becomes taller:

  * trapped water can be calculated

---

### Brute Force Approach (Optional)

### Idea

* For every index:

  * Find tallest bar on left
  * Find tallest bar on right
* Water stored:

  * `min(leftMax, rightMax) - currentHeight`

### Java Code

```java id="4a6r1q"
public class TrappingRainWaterBrute {

    public static int trap(int[] height) {

        int n = height.length;
        int water = 0;

        for (int i = 0; i < n; i++) {

            int leftMax = 0;
            int rightMax = 0;

            for (int j = 0; j <= i; j++) {
                leftMax = Math.max(leftMax, height[j]);
            }

            for (int j = i; j < n; j++) {
                rightMax = Math.max(rightMax, height[j]);
            }

            water += Math.min(leftMax, rightMax) - height[i];
        }

        return water;
    }

    public static void main(String[] args) {

        int[] height = {4,2,0,3,2,5};

        System.out.println(trap(height));
    }
}

// Time Complexity - O(N^2)
// Space Complexity - O(1)
```

### Optimized Approach

### steps for optimized approach

1. Use stack to store indices
2. Traverse array from left to right
3. When current height is greater than stack top:

   * pop middle bar
   * calculate width
   * calculate trapped water
4. Push current index into stack

### Java Code

```java id="h6x5bi"
import java.util.*;

public class TrappingRainWaterStack {

    public static int trap(int[] height) {

        int n = height.length;
        int water = 0;

        Stack<Integer> stack = new Stack<>();

        for (int i = 0; i < n; i++) {

            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {

                int middle = stack.pop();

                if (stack.isEmpty()) {
                    break;
                }

                int left = stack.peek();

                int width = i - left - 1;

                int boundedHeight =
                        Math.min(height[left], height[i]) - height[middle];

                water += width * boundedHeight;
            }

            stack.push(i);
        }

        return water;
    }

    public static void main(String[] args) {

        int[] height = {4,2,0,3,2,5};

        System.out.println(trap(height));
    }
}

// Time Complexity - O(N)
// Space Complexity - O(N)
```


### Java Code

```java id="x9j6ut"
public class TrappingRainWater {

    public static int trap(int[] height) {

        int left = 0;
        int right = height.length - 1;

        int leftMax = 0;
        int rightMax = 0;

        int water = 0;

        while (left < right) {

            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);

            if (leftMax < rightMax) {

                water += leftMax - height[left];
                left++;

            } else {

                water += rightMax - height[right];
                right--;
            }
        }

        return water;
    }

    public static void main(String[] args) {

        int[] height = {4,2,0,3,2,5};

        System.out.println(trap(height));
    }
}

// Time Complexity - O(N)
// Space Complexity - O(1)
```
