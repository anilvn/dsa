# Longest String With Only 2 Distinct Characters (No Adjacent Repeat)

### Problem Statement

* Given a string, keep only 2 distinct characters by removing all others.
* The remaining string must:

  * contain exactly 2 unique characters
  * alternate continuously
  * not contain same adjacent characters
* Return the maximum possible length.

---

### Example

#### Input

```text
beabeefeab
```

#### Output

```text
5
```

Explanation:

```text
Filtered string using 'a' and 'b' => "babab"
```

---

### Idea / Intuition

* Find all unique characters
* Try every possible pair of characters
* Build a new string using only those 2 characters
* Check:

  * adjacent characters should not be same
* Track maximum valid length

---

### Brute Force Approach (Optional)

* Generate all possible subsequences
* Check:

  * contains exactly 2 unique characters
  * alternating pattern
* Return maximum length

Very expensive because subsequences are exponential.

---

### Java Code

```java
// Time Complexity - O(2^n)
// Space Complexity - O(n)

import java.util.*;

public class Main {

    static int max = 0;

    public static int alternate(String s) {

        generate("", 0, s);

        return max;
    }

    static void generate(String curr, int index, String s) {

        if (index == s.length()) {

            if (isValid(curr)) {
                max = Math.max(max, curr.length());
            }

            return;
        }

        generate(curr + s.charAt(index), index + 1, s);

        generate(curr, index + 1, s);
    }

    static boolean isValid(String s) {

        Set<Character> set = new HashSet<>();

        for (int i = 0; i < s.length(); i++) {

            set.add(s.charAt(i));

            if (i > 0 && s.charAt(i) == s.charAt(i - 1)) {
                return false;
            }
        }

        return set.size() == 2;
    }

    public static void main(String[] args) {

        String s = "beabeefeab";

        System.out.println(alternate(s));
    }
}
```

### Optimized Approach

### Steps for Optimized Approach

1. Store all unique characters
2. Try every pair of characters
3. Traverse original string
4. Keep only selected pair characters
5. If adjacent characters become same:

   * pair is invalid
6. Update maximum valid length

---

### Java Code

```java
import java.util.*;

class Solution {

    static int longestAlternate(String str) {

        Set<Character> set = new HashSet<>();

        for (char ch : str.toCharArray()) {
            set.add(ch);
        }

        List<Character> chars = new ArrayList<>(set);

        int max = 0;

        // try every pair
        for (int i = 0; i < chars.size(); i++) {

            for (int j = i + 1; j < chars.size(); j++) {

                char ch1 = chars.get(i);
                char ch2 = chars.get(j);

                StringBuilder sb = new StringBuilder();

                // keep only 2 chars
                for (char ch : str.toCharArray()) {

                    if (ch == ch1 || ch == ch2) {
                        sb.append(ch);
                    }
                }

                // validate alternating
                if (isValid(sb)) {
                    max = Math.max(max, sb.length());
                }
            }
        }

        return max;
    }

    static boolean isValid(StringBuilder sb) {

        if (sb.length() < 2) {
            return false;
        }

        for (int i = 1; i < sb.length(); i++) {

            if (sb.charAt(i) == sb.charAt(i - 1)) {
                return false;
            }
        }

        return true;
    }

    public static void main(String[] args) {

        System.out.println(longestAlternate("beabeefeab"));
        System.out.println(longestAlternate("plapilbplcpablab"));
    }
}
```

```text
// Time Complexity - O(k² × n)
// Space Complexity - O(n + k)
```

Where:

```text
k = number of unique characters
n = string length
```
