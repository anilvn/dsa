# Longest String With Only 2 Distinct Characters (No Adjacent Repeat)

Given a string, pick only **2 distinct characters** and remove all others.

The remaining string must:

* use exactly 2 unique characters
* alternate continuously
* no same adjacent characters

Return the maximum possible length.

---

## Example

Input:

```text
"beabeefeab"
```

Possible valid string:

```text
"babab"
```

Length:

```text
5
```

---

# Brute Force Approach

## Idea

1. Find all unique characters.
2. Try every pair of characters.
3. Build a filtered string using only those 2 chars.
4. Check if alternating.
5. Track max length.

---

# Java Code

```java
import java.util.*;

class Solution {

    static int longestAlternate(String str) {

        Set<Character> set = new HashSet<>();

        for (char ch : str.toCharArray()) {
            set.add(ch);
        }

        List<Character> chars = new ArrayList<>(set);

        int max = 0;

        // try every pair
        for (int i = 0; i < chars.size(); i++) {

            for (int j = i + 1; j < chars.size(); j++) {

                char ch1 = chars.get(i);
                char ch2 = chars.get(j);

                StringBuilder sb = new StringBuilder();

                // keep only 2 chars
                for (char ch : str.toCharArray()) {

                    if (ch == ch1 || ch == ch2) {
                        sb.append(ch);
                    }
                }

                // validate alternating
                if (isValid(sb)) {
                    max = Math.max(max, sb.length());
                }
            }
        }

        return max;
    }

    static boolean isValid(StringBuilder sb) {

        if (sb.length() < 2) {
            return false;
        }

        for (int i = 1; i < sb.length(); i++) {

            if (sb.charAt(i) == sb.charAt(i - 1)) {
                return false;
            }
        }

        return true;
    }

    public static void main(String[] args) {

        System.out.println(longestAlternate("beabeefeab"));
        System.out.println(longestAlternate("plapilbplcpablab"));
    }
}
```

---

# Output

```text
5
9
```

---

# Time Complexity

Let:

* `n` = string length
* `k` = unique characters

```text
O(k² * n)
```

Because:

* every pair of chars checked
* each check scans string once

---

# Important Observation

You may think:

> "Can sliding window work?"

Not properly.

Because characters are removed from anywhere, not from contiguous substring.

This is a:

* filtering
* pair checking
* validation problem

not a substring/window problem.
