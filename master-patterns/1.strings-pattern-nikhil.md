# Longest Common Subsequence (LCS)

Question:
Given two strings, find the length of the longest common subsequence.

Input:

```text
s1 = "abcdaf"
s2 = "acbcf"
```

Output:

```text
4
```

Common Subsequence:

```text
abcf
```

# Edit Distance

Question:
Given two strings, return the minimum number of operations required to convert string1 into string2.

Allowed Operations:

* Insert
* Delete
* Replace

Input:

```text
word1 = "horse"
word2 = "ros"
```

Output:

```text
3
```

Operations:

```text
horse -> rorse   (replace 'h' with 'r')
rorse -> rose    (remove 'r')
rose  -> ros     (remove 'e')
```

# Decode Ways (LeetCode 91)

Question:
A message containing letters from A-Z is encoded using:

```text
'A' -> 1
'B' -> 2
...
'Z' -> 26
```

Given a string containing digits, return the total number of ways to decode it.

Example:

```text
Input:
s = "226"

Output:
3
```

Decodings:

```text
2 2 6 -> "BBF"
22 6  -> "VF"
2 26  -> "BZ"
```

# Word Break (LeetCode 139)

Question:
Given a string and a dictionary of words, determine if the string can be segmented into valid dictionary words.

Example:

```text
Input:
s = "leetcode"
wordDict = ["leet", "code"]

Output:
true
```

Explanation:

```text
"leetcode" = "leet" + "code"
```
