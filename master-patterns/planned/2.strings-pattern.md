

## FINAL STRING DSA STRUCTURE (Pattern-Based)



## 1. Basic String Operations

(Foundation – must be instant)

* Reverse a string (in-place)
* Check if a string is a palindrome
* Valid palindrome (ignore non-alphanumeric)
* Check if one string is rotation of another
* Check if string is a subsequence of another
* Longest common prefix
* Compare version numbers

---

## 2. Hashing / Frequency Based

(Counting + maps)

* Check if two strings are anagrams
* Group anagrams
* Find all anagram indices in a string
* Find first non-repeating character
* Check isomorphic strings
* Word pattern matching
* Reorganize string (no adjacent same chars)

---

## 3. Sliding Window Pattern

(MOST IMPORTANT for strings)

### Core Window Problems

* Longest substring without repeating characters
* Longest substring with at most K distinct characters
* Longest repeating character replacement

### Window Matching Problems

* Minimum window substring
* Smallest window containing all characters of another string

---

## 4. Two Pointers Pattern

(Simple scanning / shrinking)

* Valid palindrome (optimized two-pointer version)
* Check subsequence
* Find substring index (`strStr()` basic approach)

---

## 5. Stack-Based / Parentheses Pattern

(This is where stack comes clearly)

* Valid parentheses
* Longest valid parentheses
* Generate all valid parentheses
* Remove outermost parentheses
* Decode string (e.g., `"3[a2[c]]"`)

---

## 6. Greedy + Heap / Rearrangement

* Reorganize string
* Longest happy string

---

## 7. Mathematical / Simulation

* String to integer (atoi)
* Count and say
* Roman to integer / Integer to Roman

---

## 8. String Arithmetic

* Add binary strings
* Add numeric strings
* Multiply two large numbers (strings)

---

## 9. Pattern Matching Algorithms (IMPORTANT GROUP)

(These are NOT sliding window — separate category)

* Rabin-Karp
* KMP (Knuth-Morris-Pratt)
* Z-algorithm
* Longest prefix which is also suffix (LPS concept)

---

## 10. Dynamic Programming on Strings

(Hard but very important)

* Longest common subsequence (LCS)
* Longest common substring
* Edit distance (Levenshtein distance)
* Minimum deletions to make strings equal
* Minimum insertions to make string palindrome

---

## 11. Palindrome-Based Advanced

* Count palindromic substrings
* Longest palindromic substring
* Shortest palindrome (add chars in front)

---

## 12. Encoding / Decoding / Design

* Encode and decode strings
* String compression

---
